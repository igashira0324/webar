📱 Android Chrome で開き、ENTER AR ボタンから AR を起動してください。

ABOUT

ブラウザを開くだけで、3D MMD モデルが現実空間に登場する WebAR 体験です。 アプリのインストールは不要。スマホのカメラと WebXR 対応ブラウザだけで動作します。

USAGE / 使い方

① ENTER AR をタップして AR モードへ。
② カメラを動かして平面（床や机）を認識。
③ 画面をタップした場所にアバターが登場します。
④ アバターをタップ：ダンスの再生 / 一時停止。
⑤ 画面全体の操作（アバター以外の場所を操作してください）：
  ・1本指ドラッグ：アバターを回転
  ・2本指ピンチ：アバターを拡大・縮小

SUPPORTED DEVICES

✅ Android (Chrome 90+) — フル対応
⚠ iOS (Safari) — WebXR 非対応のため AR 起動不可
✅ デスクトップ — 通常の 3D ビューワとして動作

TECH STACK / 技術スタック

レンダリング: Babylon.js（WebGL2）
3Dモデル: babylon-mmd（PMX / VMD ローダ）
AR基盤: WebXR Device API + ARCore
言語 / ビルド: TypeScript + Vite
配信: Vercel（HTTPS / Edge）

📱

AR 非対応の環境です
