CHAPTER 01

COVER / 概要

本ドキュメントは「生成AIなんでも展示会 Vol.5」におけるWebAR MMDデモの技術解説書です。アプリインストール不要で、Webブラウザのみで高品質な3Dキャラクター体験を実現するための知見を凝縮しました。

CHAPTER 02

OVERVIEW / コンセプト

「ブラウザを開くだけで、目の前にミクが現れる」という直感的なユーザー体験をコアに据えています。高度な環境認識（WebXR）と物理演算（Ammo.js）を融合させ、モバイル端末でも快適な描画を維持します。

💡 KEY CONCEPT: ゼロ・インストール。QRコードを読み取ってから3秒以内にAR体験を開始することを目指しました。
CHAPTER 03

TECH STACK / 技術構成

モダンなWeb技術を駆使し、デスクトップ級の3D表現をモバイルブラウザへ最適化しています。

CHAPTER 04

WEBXR / ブラウザ型AR

WebXR Device APIを使用し、カメラの姿勢推定と現実の座標系を同期。ARCore (Android) および WebXR Viewer (iOS) に対応しています。

const xr = await scene.createDefaultXRExperienceAsync({
  uiOptions: { sessionMode: 'immersive-ar' }
});
CHAPTER 05

BABYLON.JS / 描画エンジン

高機能なBabylon.jsを採用し、PBR（物理ベースレンダリング）とMMDのセルシェーダーを共存させています。照明推定により、現実の明るさに合わせてキャラクターの影が動きます。

CHAPTER 06

MMD / モデル実装

PMX形式のモデルとVMD形式のモーションをリアルタイムでデコード。MMD特有の「剛体物理」をAmmo.js上で忠実に再現し、髪やスカートの揺れを実現しています。

CHAPTER 07

DUAL-AUDIO / 立体音響

BGMとキャラクターボイスを分離し、Web Audio APIを用いて3D空間オーディオを実現。ユーザーの向きに合わせて声の聞こえる方向が変化します。

CHAPTER 08

HIT-TEST / 空間固定

Hit Test APIを利用し、スマートフォンのカメラで検出した床面に仮想のマーカーを設置。タップした瞬間にキャラクターが現実世界に着地します。

DESIGN / 設計判断

「モバイルでの描画負荷」と「キャラクターのクオリティ」のトレードオフをどう解決したか。具体的には、テクスチャのKTX2圧縮とシェーダーの簡略化を選択しました。

CHAPTER 11

FAQ / よくある質問

Q: iPhoneで動作しません。
A: iOSではWebXR Viewerアプリを使用するか、Apple公式のWebXR sessionを有効にする必要があります。

Q: モデルが浮いてしまいます。
A: 床面検知が完了するまで十分にカメラを動かしてからタップしてください。
