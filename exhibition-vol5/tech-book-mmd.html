MMD × WebXR Experience

MikuMikuDanceモデルをブラウザだけで実空間に呼び出し、高品質なアニメーションを実現するWebAR実装の解説。

コンセプト

専用アプリのインストールを必要とせず、スマートフォンのブラウザ（Chrome/Safari）だけで動作するWebAR体験。MMDモデルの豊かな表現力をWebXR APIとBabylon.jsを組み合わせて実現しました。

技術スタック

  • Rendering Engine: Babylon.js (v6.x)
  • WebXR Support: Babylon.js WebXR Experience Helper
  • Model Loading: babylon-mmd (MMD-related file loader)
  • Physics: Ammo.js (MMD 剛体物理シミュレーション)
  • State Management: Vite + TypeScript

実装のポイント

1. babylon-mmdの活用: PMX/VMDファイルを読み込み、MMD特有のボーン構造、モーフ、物理演算をブラウザ上で再現。

2. WebXR Hit Test: 床面を検知し、モデルを現実世界に固定。照明推定（Lighting Estimation）を反映させ、現実の光環境に馴染ませる調整を行っています。

3. パフォーマンス最適化: モバイル端末での動作を考慮し、テクスチャの圧縮（KTX2）や、物理演算の計算頻度を調整。60FPSを維持するための描画パイプラインの構築。
